# Frontend

React/Next.js dApp (Pratham owns this folder). Not built yet.

Planned screens: wallet connection, create campaign, contribute, vote on a milestone, and a progress dashboard built from contract events. IPFS uploads go through Pinata.

The app reads these values from its environment file after deployment:

```
NEXT_PUBLIC_USDC_ADDRESS=
NEXT_PUBLIC_FACTORY_ADDRESS=
```
